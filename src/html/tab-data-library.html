Seuls les résultats en CSV (directement exploitables ci-dessous) proposent « + Charger » ; les autres formats (GeoJSON, KML, PDF…) sont à ajouter comme couche depuis l'onglet Bib. à la place.
La 1re ligne = en-têtes. Peut être joint par nom de commune ou code INSEE/AGS.

Aperçu
Recherche en direct
Interroge en direct les géocatalogues GIS-GR, Géoportail Luxembourg, Open Data Luxembourg (data.public.lu) et STATEC/LUSTAT — pour trouver un jeu de données absent du catalogue ci-dessous. Seuls les résultats en GeoJSON (directement intégrables comme couche) proposent « + Ajouter » ; les CSV se cherchent plutôt depuis l'onglet Données (jointure par nom/code), les autres formats (KML, PDF…) ne sont pas affichés.
Catalogue GIS-GR
Jeux de données réels du Géoportail de la Grande Région — cliquez « + Ajouter » pour les récupérer et les afficher comme n'importe quelle couche importée.
Fonds de carte pour Datawrapper
GeoJSON prêts à importer (Carte choroplèthe → Personnalisée), poids sous la limite de 2 Mo, codes officiels corrigés. Chaque fond a son CSV de données de base (id, nom, initiales, pays…) à coller dans l'onglet Données de Datawrapper : choisissez id comme clé. Un fichier par territoire est plus léger et plus précis que le fichier toute Grande Région.
